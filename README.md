# Graph Connectivity via BFS

Java implementation that reads graph definitions from a file and determines 
whether pairs of nodes are connected using breadth-first search.

## Key Concepts
- Undirected graph representation using HashMap<String, HashSet<String>>
- Breadth-first search with queue and visited set
- File-based input parsing

## How to Run

javac *.java

java GraphQRunner

(requires graph1.dat in working directory)
